# 🕒 Digital Timekeeper

A modern, interactive digital clock application built with **HTML, CSS, and JavaScript**, designed with an artistic UI and practical real-time features.

---

## 🚀 Overview

Digital Timekeeper is a front-end mini application that demonstrates core JavaScript concepts such as **DOM manipulation, state management, and time-based updates**, wrapped in a visually engaging interface.

The project focuses on delivering both **functionality and user experience**, combining clean code practices with subtle animations and responsive design.

---

## ✨ Features

* ⏱ **Real-Time Clock**
  Displays live time with automatic updates every second.

* 🔁 **12-Hour / 24-Hour Toggle**
  Seamlessly switch between time formats with AM/PM support.

* 🌗 **Dark / Light Theme Switcher**
  Dynamic theme toggling with smooth transitions.

* 📅 **Full Date Display**
  Shows the current day, date, and year in a readable format.

* 🔔 **Top-of-the-Hour Alert**
  Triggers a sound notification when a new hour begins.

* ✨ **UI Animations**
  Includes glow effects, smooth transitions, and interactive button feedback.

* 🎨 **Custom Digital Aesthetic**
  Styled using the Orbitron font for a futuristic clock feel.

---

## 🧠 Technical Highlights

This project demonstrates:

* **JavaScript Objects & Methods**
  Encapsulated logic using a `clockApp` object.

* **State Management**
  Controlled app behavior using global state variables (e.g., time format, theme).

* **DOM Manipulation**
  Dynamically updates time and date in real-time.

* **Event Handling**
  Handles user interactions such as button clicks.

* **Timing Functions**
  Uses `setInterval()` for continuous updates.

* **Conditional Logic**
  Implements 12/24-hour conversion and alert triggers.
